# M1 test results

Recorded 2026-10-05 on the author's machine (Intel Core i7-13700H, Windows 11, OpenJDK 21.0.12,
Maven 3.9.11, JUnit 6.1.3). CI re-runs everything on Ubuntu with Temurin 21 on every push.

## Tests: 165 passed, 0 failed

Command: `make test` (`mvn verify`). Lint: `make lint` compiles with `-Xlint:all -Werror` (no
warnings).

| Test class | Tests | What it proves |
|---|---|---|
| `LexerTest` | 19 | Token kinds and exact spans, two-character operators, exact decimals, escapes including `\u{1F600}`, keywords vs names, and nine kinds of bad input each with a clear message and an in-range span |
| `ParserTest` | 51 | 24 precedence and associativity cases (for example `not a == b` is `not (a == b)`), the README example's exact tree, spans including parentheses, match patterns, 20 syntax errors with exact messages and hints, and the nesting limit |
| `RoundTripPropertyTest` | 3 | Over 3,000 random trees: printing then parsing is the identity; every node's span, cut out and parsed alone, gives that node (also for the example files) |
| `TypeCheckerTest` | 48 | Ten well-typed rules infer the right type; every node is typed; 40 classes of mistake each give one exact message; suggestions; the offending operand is underlined; three independent errors reported together; one typo gives one error; the host can require a result type |
| `DiagnosticRenderTest` | 5 | Exact rendered output: line and column, tabs, emoji counted as one column, an error at the end of the rule, wide line numbers |
| `ExamplesTest` | 14 | The three example rules check against `examples/pricing.schema`; the eleven broken examples print exactly their stored `.expected` snapshot |
| `MainTest` | 4 | CLI exit codes (0 valid, 1 rule errors, 2 usage), output format, `ast` command |
| `SchemaTest` | 8 | Nested records, enums and lists; rules reading nested lists; six invalid schemas rejected with the reason |
| `RobustnessTest` | 13 | 5,000 random strings, 20,000 random token sequences and 3,000 random trees never throw; nine pathological nesting shapes (20,000 levels of parentheses, minus signs, `not`, `.field`, `+`, brackets, `if`, `let`, calls) each end in one "nested too deeply" diagnostic; a flat 10,000-item list is fine |

### Mutation check

To show the tests can fail, six deliberate bugs were applied one at a time and the suite re-run
(then the source was restored):

| Mutation | Tests that failed |
|---|---|
| `+` and `-` made right-associative | 2 of 165 |
| Chained comparisons allowed | 4 of 165 |
| `match` exhaustiveness check removed | 4 of 165 |
| Nesting limit removed (200 to 2,000,000) | 10 of 165 (stack overflows) |
| Enums no longer count as text | 4 of 165 |
| Wrong operand underlined in arithmetic errors | 3 of 165 |
